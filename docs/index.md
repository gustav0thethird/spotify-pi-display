# Overview

The Spotify Display project is designed to create a visual display for showing the currently playing track on Spotify using a Raspberry Pi. This project aims to enhance the user experience by providing a dedicated screen that displays real-time information about the music being played.

## Purpose

The primary purpose of the Spotify Display project is to provide an easy-to-use interface for users to see what music is currently playing on their Spotify account. By utilizing a Raspberry Pi, the project leverages affordable hardware to create a functional and interactive display.

## Features

- **Real-time Display**: Shows the currently playing track, including the song title and artist name.
- **Raspberry Pi Compatibility**: Specifically designed to run on Raspberry Pi hardware, making it accessible and cost-effective.
- **Python Implementation**: Built using Python, allowing for easy modifications and enhancements by users familiar with the language.
- **Service Integration**: Functions as a service that can be easily managed and integrated into existing setups.
- **Customizable Templates**: Utilizes Jinja2 templates for easy customization of the display layout and design.
- **Setup Scripts**: Includes scripts for managing the display setup and configuration, simplifying the installation process.

For more information, refer to the [GitHub repository](https://github.com/gustav0thethird/spotify-pi-display).
