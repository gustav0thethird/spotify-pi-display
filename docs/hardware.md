# Hardware Requirements

To set up the Spotify Display using a Raspberry Pi, the following hardware components are required:

## Required Components

1. **Raspberry Pi**
   - Any model that supports Wi-Fi and has a compatible display interface. Recommended models include:
     - Raspberry Pi 3
     - Raspberry Pi 4

2. **Display**
   - A compatible display that connects to the Raspberry Pi. Options include:
     - HDMI display
     - TFT display (e.g., 480x320 resolution)

3. **Power Supply**
   - A reliable power supply for the Raspberry Pi, typically rated at 5V and at least 2.5A.

4. **MicroSD Card**
   - A microSD card with a minimum capacity of 8GB for the operating system and application files.

5. **Wi-Fi Network**
   - A stable Wi-Fi connection for the Raspberry Pi to connect to the internet and access Spotify services.

6. **Optional: USB Keyboard and Mouse**
   - For initial setup and configuration, a USB keyboard and mouse may be helpful.

## Additional Considerations

- Ensure that the Raspberry Pi has the necessary software installed, including the operating system and any required libraries for the display and Spotify integration.
- If using a TFT display, ensure that the appropriate drivers are installed and configured for the display to function correctly with the Raspberry Pi.
- The setup may require additional components such as jumper wires or a breadboard if using GPIO pins for display connections.

This hardware setup will enable the Raspberry Pi to function as a Spotify now-playing display.
